# Human Free Will Behaviors

Three hand-painted gardens in the browser, where about seventy tiny people each decide for themselves what to do next. Select anyone to read how they decide.

Play: https://gokayfem.github.io/free-will-gardens/

- [The Gate](https://gokayfem.github.io/free-will-gardens/)
- [The Orchard](https://gokayfem.github.io/free-will-gardens/?garden=orchard)
- [The Lily Court](https://gokayfem.github.io/free-will-gardens/?garden=lily-court)

This repository holds the built game only. Made with Three.js.
